# T08 专项评审｜Competition Metrics Engine

## 范围

- Top3 / Top10 ASIN 销量集中度
- Top3 / Top10 品牌销量集中度
- BSR Top1/5/10/20/30/50/70/100 累计销量、份额、同比
- 头部相对大盘变化差值
- `head_up_broad_down` 等描述性结构信号

## 开源复用

现有开源 Amazon research 项目普遍已有品牌/市场份额聚合，可复用字段组织和报告结构；未找到与制冰机历史流程完全一致的 BSR 分层同比 + 头部虹吸实现，因此本模块保持纯 Python 小实现。

## 计算口径

- ASIN 集中度按月销量降序。
- 品牌集中度先按品牌汇总月销量，再降序。
- 品牌缺失时每个 ASIN 视作独立未知品牌，防止多个缺失值被错误合并成一个超大“UNKNOWN 品牌”。
- BSR 分层按 `node_rank` 升序，而不是按销量排序；缺失 rank 的产品排到后面。
- 头部信号只描述结构，不直接得出商业结论。

## Golden Case 对应

后续全链路可直接验证制冰机冻结基线：

- Top3 ASIN ≈ 21.7%
- Top10 ASIN ≈ 47.8%
- Top3 品牌 ≈ 50.2%
- Top10 品牌 ≈ 85.8%

本模块本身不写死这些数值，只在 Integration Test 中拿重新计算结果对比。
