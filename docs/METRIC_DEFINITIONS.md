# 指标口径定义（第一批整改）

本文件固化会直接影响选品判断的统计口径。代码以此为准；口径变更必须同步修改本文件与对应测试
（`tests/test_metric_definitions_batch1.py`）。标注“待确认”的是原需求文字不够明确、由工程暂定的部分，
需客户用人工对账样本确认。

| 指标 | 口径 | 缺数据时 |
|---|---|---|
| 跨父体去重 | 同月内 **销量、评分、评分数三者完全相同**（且评分数>0）视为同一商品，保留销量/排名更优者；每组去重写入 `quality.json` 的 `dedupe_audit`（保留谁、删掉谁） | 评分或评分数缺失/为 0 → 无法判重，原样保留，计入 `dedupe_unjudgeable_rows` |
| 旧口径（品牌+标题） | 默认**关闭**；`ingest --dedupe-title` 显式开启，仅作人工对比 | — |
| 同父体去重 | 保留销量最高（并列取更优排名、ASIN 字典序） | — |
| 逐名次销量 | `rank_points`：第 1、2、3、5、10、20、30、50、100 名**各自**销量及同比。**已确认口径：按位次取第 N 名**——先按节点排名排序（缺排名者按销量降序排在其后），再取第 N 个；去重或多节点合并造成的名次空缺/重复不影响“第 N 名”的含义。每点输出 `asin` 便于核对 | 该位次不存在 → `None`（未知），不是 0 |
| 累计层级 | `rank_layers`：前 N 名累计，与逐名次销量是两个不同指标，报告中分别标注 | — |
| ASIN 集中度 | Top3/Top10 ASIN 销量占比 | — |
| 品牌集中度 | Top3/Top10 品牌销量占比；缺品牌者各自独立成组（占比为下界），并输出 `brand_coverage_pct` | 覆盖率可见 |
| 卖家集中度 | 由**卖家名**计算，不得用品牌顶替；输出 `seller_coverage_pct` | 无任何卖家数据 → `None` |
| 成功率 | 连续 N 月达标新品 / 全部有效新品 | — |
| **留存率** | 当期销量 ≥ 存活阈值的新品 / **全部有效新品**。**已确认口径：分子不要求历史连续达标**——只看当期是否仍达标，与“成功率”（连续 N 月达标）相互独立 | 当期未观测 → 计入 `retention_unknown_products`，并给出上界 |
| **推广率** | 上架后首 N 个月（默认 3，含上架月）内任一月销量 ≥ **人工设定的推广阈值**的新品 / 全部有效新品 | 未设阈值 → 不计算；窗口月份缺失或窗口未走完且未达标 → 未知，并给出上界 |
| 历史成功者存活率 | 保留，仅作补充，分母为已观测的成功新品，**不得**当作留存率 | — |

CLI：`analyze --promotion-threshold <腰部销量> --promotion-window 3`。
