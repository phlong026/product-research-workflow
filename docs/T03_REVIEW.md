# T03 专项评审｜Monthly BSR Pipeline

## 业务顺序
原始月度榜单 → 解析字段 → 父体去重 → 疑似重复（同品牌+标准化标题）去重 → 按月销量降序 → Top100。

## 开源调研
- SellerSprite/Sorftime 已有 Top100/Top200 数据获取能力，可复用作为输入。
- 公开项目普遍直接消费平台 Top100；未发现与制冰机案例完全一致的“父体去重 + 疑似重复 + Top100”通用实现，因此该小段按客户真实流程自行实现。

## 最小化设计
- 核心转换纯 Python，无 LLM。
- Excel 读取放在可替换 I/O Adapter；生产用 Polars + calamine，核心测试不依赖 Excel 包。
- TopN、CN(HK)合并、两类去重均参数化，不把制冰机特例写死。

## 风险
“疑似重复商品”若未来需要更复杂语义判定，应在人工检查节点处理；T03 只做保守的同品牌+标准化标题去重，避免误删。
