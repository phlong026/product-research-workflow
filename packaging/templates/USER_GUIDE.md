# 操作手册

## 1. 登录与项目

- 启动:双击 `start.bat`,浏览器打开 http://127.0.0.1:8800 ;用管理员账号登录(初始口令见 `runtime\initial_admin_password.txt`)。
- 管理员可以在界面里创建其他账号;项目只有所有者与被分享的成员可见,没有权限一律显示为「不存在」。
- 新建项目:填产品名(如 Ice Maker)、站点(如 US)、可选主关键词。

## 2. 研究流程

流程按顺序推进,**每个检查点都必须你亲自点击确认,系统不会自动通过**。

| 步骤 | 你要做什么 |
|---|---|
| 数据导入 | 上传月度 BSR 文件(CSV/Excel,文件名带月份如 `2026-01.csv`),或在配置了数据源后用实时取数。可先「节点发现」,**主节点必须你确认** |
| **数据检查点** | 查看清洗结果、缺月、去重与质量警告;确认或驳回。缺月会明示,不会被当作 0 |
| 商品补齐(可选)+ **补齐检查点** | 补卖家所属地与卖点(需卖家精灵会话);做了补齐就必须确认后才能分类 |
| 分类 | 填分类标签与关键词规则(或选 LLM 分类);机器拿不准的行标为「待人工」 |
| **分类检查点** | 逐项复核分类,待人工的必须由你指定标签 |
| 分析 | 计算市场、竞争、新品指标。**推起阈值与留存阈值需要你自己给出数值**(系统没有默认值),否则不计算新品指标并在报告里说明 |
| **路线检查点** | 系统按指标给出可选的后续研究方向,你选择要做的 |
| 资料包 | 生成并下载资料包:`report.md`、`dashboard.html`、`research_workbook.xlsx`(综合 Excel)、各类 CSV、证据与哈希清单 |

最终商业结论栏在资料包里留空,**由你自己填写**。

## 3. 人工修改数据

在项目页可导出三张表(清洗月度数据 / 唯一 ASIN 的卖点与地区 / 分类结果)到 Excel 修改后再上传。校验失败不会改动任何状态;成功后旧的确认自动失效,需要重新确认。

## 4. 外部证据(可选)

趋势、研报摘录、TikTok 台数、专利检索、广告、大品牌、站外渠道、关键词、使用场景、用户评论主题等,可作为「证据」登记,登记后会进入资料包并在「深挖研究」里列出各项证据是否齐全。每次登记必须写明来源、取数日期和取数范围;缺失的数字显示为缺失,不会补成 0。

## 5. 实时取数(可选)

- SIF / 西柚 / Apify:把凭据填入安装目录的 `.env` 即可(用记事本编辑,保存后重启 `start.bat`)。
- 卖家精灵:需要 Node.js 22+ 和 Chrome。安装 Node.js 后执行 `npm install -g github:JieXi-11/SellerSprite`,用 `--remote-debugging-port=9222` 启动一个专用 Chrome 并在其中登录卖家精灵,`.env` 里 `SELLERSPRITE_CDP_URL=http://127.0.0.1:9222`。详细步骤见 Codex 或技术支持。
- 运行 `check.bat` 可查看凭据是否已填(不显示密钥)。

## 6. 数据与备份

- 所有项目数据都在 `runtime\` 目录。备份时关闭工作台后复制整个目录。
- `runtime\initial_admin_password.txt` 用完请删除。

## 7. 常见问题

| 问题 | 处理 |
|---|---|
| 浏览器打不开页面 | 确认 `start.bat` 的黑色窗口还开着;端口被占用时设置环境变量 `XUANPIN_PORT` 后重启 |
| 忘记管理员口令 | 当前版本没有网页改口令。关闭工作台后,在安装目录打开命令行,用新用户名创建一个新的管理员账号(会提示输入口令):`.venv\Scripts\python.exe -m research_workflow.web create-user --username admin2 --role admin` |
| 作业失败 | 页面会显示业务错误原因(如缺月、阈值未设置);修正输入后点「重试」 |
| 想让同事一起用 | 本版本默认只监听本机。多人访问须放在 HTTPS 反向代理后并先做安全评审,请联系技术支持 |
