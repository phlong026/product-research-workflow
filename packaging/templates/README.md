# 跨境选品研究工作台(客户安装包)

Amazon 跨境选品的研究工作流:数据导入 → 人工检查点 → 分类 → 市场/竞争/新品分析 → 研究资料包。
**最终的商业判断(要不要做)始终由你自己决定,系统不给 Yes/No 建议。**

## 快速开始(Windows)

1. 解压本压缩包到一个固定目录(如 `C:\xuanpin`,路径里最好没有中文和空格)。
2. 双击 `install.bat`,等待安装完成(首次需联网,约 5–15 分钟)。
3. 双击 `start.bat`,浏览器会打开 http://127.0.0.1:8800 。
4. 用管理员账号 `admin` 登录。初始口令保存在 `runtime\initial_admin_password.txt`,记下后请删除该文件。

在 Codex 里安装:把本目录交给 Codex,让它阅读并执行 `INSTALL_FOR_CODEX.md`。

## 文件说明

| 文件 | 作用 |
|---|---|
| `install.bat` / `install.ps1` | 一键安装(可重复运行,不会覆盖你的数据和配置) |
| `start.bat` | 启动工作台(只监听本机) |
| `check.bat` | 体检:依赖是否齐全、数据源凭据是否已填(不显示密钥) |
| `.env` | 数据源凭据(安装后生成,默认全空;只存放在你本机) |
| `runtime\` | 你的项目数据、账号库。**请定期备份这个目录** |
| `USER_GUIDE.md` | 操作手册 |
| `INSTALL_FOR_CODEX.md` | 给 Codex 的安装步骤 |

## 升级

下载新版压缩包解压到**新目录**,把旧目录的 `runtime\` 和 `.env` 复制过去,再运行新目录的 `install.bat`。

## 卸载

关闭工作台后直接删除整个目录即可(先备份 `runtime\`)。uv 与其下载的 Python 位于用户目录,不影响系统 Python,可按需另行卸载。

## 当前版本的边界(请务必阅读)

- 本版本在合成数据上做了离线测试;**尚未用真实的卖家精灵 / SIF / 西柚 / Apify / 大模型接口联调**,也未用客户业务样本逐项对账。实时取数前请先用少量数据试跑并与你的人工结果核对。
- 不填任何数据源凭据也可以用:把卖家精灵等导出的 CSV/Excel 上传即可。
- 工作台只监听本机(127.0.0.1)。**不要直接暴露到公网**;多人使用须放在 HTTPS 反向代理之后并先做安全评审。
